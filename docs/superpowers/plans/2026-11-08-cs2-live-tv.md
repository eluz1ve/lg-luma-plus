# CS2 live: телевизор (lg-luma) — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Luma+ показывает счёт по раундам на главной (виджет, тайлы карт, «Сегодня») и полный
live в карточке матча: скорборд, историю раундов, game log с иконками CS2 и строку стримов.

**Architecture:** Новый модуль `src/cs2-live.rs` (типы, разбор, планировщик запросов) рядом с
`cs2.rs`; запросы — в существующем воркере `cs2-service.rs` на отдельном потоке. Рисование — в
`view.rs` рядом с `cs2_dialog`/`cs2_card_maps`/`today_*`, новые крупные куски выносятся в
`src/cs2-live-view.rs`. Данные приходят только с `luma.eluzive.dev` (формат — Task 2 серверного
плана).

**Tech Stack:** Rust 1.93, SDL2/GLES2, ureq/rustls, serde_json; SVG → `.lvec` через
`tools/vector-assets.mjs`.

**Spec:** `docs/superpowers/specs/2026-11-08-cs2-live-scorebot-design.md`; макет
`live-card-v5.html` (копия в scratchpad сессии, раскладка описана в spec). Серверный план:
`docs/superpowers/plans/2026-11-08-cs2-live-server.md`.

## Global Constraints

- Ветка `cs2-live` от `fork/integration`; по завершении — в `integration` (fork). Не пушить в upstream-ветки PR.
- Сеть — вне SDL-потока; лимит ответа, таймаут 8 с, без редиректов и прокси (как `cs2-service.rs`).
- Live-файлы только с `https://luma.eluzive.dev/cs2/live/`, без запасного GitHub Pages. `--cs2-test-server` — тот же loopback-формат, путь `/luma-feeds/cs2/live/…`.
- Карточка: 1920×1080 логических, панель `Rect::new(296., 60., 1328., 960.)` без прокрутки.
- Нет live-данных или они старше 30 с (`updated` против времени фида/часов) → карточка как сейчас, без пустых панелей.
- Стримы: сортировка по `viewers`; чип только при установленном приложении (`state.inventory.apps`); нет ни одного — строки нет.
- Новые строки интерфейса — во всех языках `assets/messages.json`.
- Иконки Valve — `assets/ui-icons/cs-*.svg` (имена `[a-z0-9-]`), источник и права — `assets/licenses/valve-cs2-icons.txt`.
- Проверка: `cargo test cs2` и сборка; smoke/полные прогоны не запускать; на ТВ ставит и смотрит пользователь (кроме Task 7 — пробы запуска делает исполнитель через ares `lgtv`).
- Коммиты от eluz1ve, без Co-Authored-By. Changeset (`pnpm changeset`, minor) — в последней задаче.

## Review Focus

- Live-файл есть, а карта в нём не совпадает с текущей картой Liquipedia (Liquipedia отстаёт) → показываем карту и счёт из live-файла, тайл карты по имени, без дублей.
- Длинные ники (`Bukhavez`, 16 символов) и длинные названия команд в полосе скорборда → `fit_text`, ничего не вылезает за колонку.
- Игроков в команде не 5 (замена, 4 после дисконнекта) → строк столько, сколько пришло, максимум 5, высота не растёт.
- Оружие без иконки (`zeus`, новое оружие) → название текстом в плашке.
- Карточку закрыли во время запроса → ответ игнорируется (поколение), опрос прекращается.
